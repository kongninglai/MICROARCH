Step 1: cd to directory with top level Verilog files
Step 2: mkdir fanout; cd fanout; module load synopsys/syn; design_vision -no_gui
Step 3: analyze -format Verilog {files}; elaborate <top_level>; current_design <top_level>; set target_library ""; set link_library "*"; link;
NOTES FOR STEP 3: top_level file should be the first one listed in {files}. Include junk.v in {files}.
Step 4: either use Mircea's script (just copy paste fanout_script.tcl) or use "all_high_fanout -nets -threshold 5"
NOTES FOR STEP 4: Mircea's script may break under some circumstances. You can mostly depend on all_high_fanout, provided you add junk.v to the file list.
EDIT: Mircea's script has been modified to now also use all_high_fanout. See fanout_script.tcl.

Example for Step 3 for PA_8b.v:
analyze -format Verilog {../PA_8b.v ../gen_prop.v ../gen_prop_2.v junk.v ~/MICROARCH/project/hdl/local-lib/gates/xor3LL.v}; 
elaborate PA_8b; current_design PA_8b; set target_library ""; set link_library "*"; link;
