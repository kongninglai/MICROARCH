# x86 Notes

This directory contains our study notes and reference materials on the x86 (IA-32) architecture.  


## Contents

- [IA-32.md](IA-32.md) — Overview of the general instruction format and the meaning of each encoding field.  

## Purpose

The goal of this directory is to serve as a technical background and reference for the project.  
It documents the essential concepts needed to understand the IA-32 architecture.
